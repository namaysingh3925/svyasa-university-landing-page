# S-VYASA University: Info Page

My first HTML page: a simple information page about **S-VYASA (Swami Vivekananda Yoga Anusandhana Samsthana)**, a deemed-to-be university in Bengaluru.

It was built with plain, semantic HTML to practise the basics: page structure, headings, paragraphs and the `<head>` metadata.

## View it

Open `index.html` in any browser.

## What I learned

- The structure of an HTML document (`<!DOCTYPE>`, `<head>`, `<body>`)
- Using headings and paragraphs for readable content
- Setting the page title and the mobile viewport
